# Quest Dimensions & Mob Hunts — English overview

A mob-hunting quest datapack tracking overlapped kill categories and dimensions, rewarding milestones and resetting progress on death.

**Official CurseForge page:** https://www.curseforge.com/minecraft/data-packs/quest-dimensions-mob-hunts

**Files/versions:** quest_multi_v3_3.zip.

Install Fabric mods in a matching mods/ setup, datapacks in the world's datapacks/ folder, Bukkit plugins in a compatible server plugins/ folder, and modpacks using a compatible launcher. Back up your worlds and verify compatibility before updating.

The French guide and verification notes are available from the [home page](../README.md).
