# Installer Quest Dimensions & Mob Hunts

**Version(s) repérée(s) :** quest_multi_v3_3.zip.

1. Télécharge le ZIP compatible depuis CurseForge.
2. Place-le dans le dossier datapacks/ de ton monde.
3. Exécute /reload ou redémarre le serveur.
4. Confirme sa présence avec /datapack list.
5. Teste ses effets sur une copie du monde.

## Avant d'installer

Source : description officielle CurseForge. ZIP v3.3 non trouvé localement ; nombres de paliers et crafts exacts non vérifiés.

Vérifie la page CurseForge : https://www.curseforge.com/minecraft/data-packs/quest-dimensions-mob-hunts.
